Public Service Request System 

A full-stack web application designed for citizens to report public utility issues (such as broken streetlights, water leaks, and potholes) and for government administrators to manage and track resolution statuses.

Features
- Citizen Authentication: Secure registration and login for citizens and administrators.
- Service Request Submission: Submit issues with categories, descriptions, and locations.
- Admin Control Dashboard: Administrators can update case statuses in real-time (`Pending` → `In Progress` → `Resolved`).
- Live Analytics: Real-time counter cards showing total cases, pending cases, cases in progress, and resolved cases.
- Modern UI/UX: Built with Tailwind CSS for a sleek, responsive government portal experience.

---

Setup & Installation Instructions

Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

Step-by-Step Run Guide
1. Open your terminal or command prompt inside the project folder (`public-service-system`).
2. Install dependencies by running: npm install
3. Start the server by running the command: 'npm start'. The message "Server running smoothly at http://localhost:3000" will be displayed once the server strats running.
4. Open your browser and navigate to http://localhost:3000
